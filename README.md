# Quizlet

A frontend project organized into separate `home` and `signuppage` sections.

## Project Structure

- `home/` — home-page related assets and markup.
- `signuppage/` — signup-page related assets and markup.

## Getting Started

Open the relevant HTML entry point from the project in a modern browser to preview the interface.

## Development

Keep page-specific assets inside their respective sections and verify navigation between pages after UI changes.
